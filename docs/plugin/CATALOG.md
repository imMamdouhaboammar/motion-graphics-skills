# Skills and engine catalog

This release contains **53 top-level skills**: 50 domain specialists and three host helpers. Video Style Cloner also bundles **36 named workflow modules** under its own `skills/` directory. Those modules include production styles, HyperFrames guidance, media utilities and review doctrine. They are supporting entry points, not 36 additional independently imported plugin skills.

Generated from the canonical folders for plugin 1.2.0. The linked source instructions define each workflow. Read only the specialist needed for the current job.
