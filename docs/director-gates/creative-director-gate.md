# Gate 1: Creative Director Quality Gate

Sign-off criteria for Phase 1 (Concept and Storyboard).

## Mandatory Sign-Off Criteria

1. **Immediate Hook (0 to 2 Seconds)**:
   - Frame 0 is already in motion.
   - Core premise is stated or visually demonstrated within the first 2 seconds.
   - Zero boring title cards or dead air before action begins.
2. **Visual Metaphor Clarity**:
   - The primary visual device (e.g. continuous light arrow, mascot journey, UI transformation) directly reinforces the brand proposition.
   - Narrative flow is mapped into a second-by-second beat sheet.
3. **Pacing and Cadence**:
   - Spoken script word count matches target duration at a natural human speaking rate (approximately 130 to 150 words per minute).
   - Text blocks hold stationary for a minimum of 0.70 seconds to guarantee viewer readability.

## Verdict Contract

- **PASS**: All 3 criteria verified against storyboard or beat-sheet document.
- **BLOCK**: Weak hook, text pace too fast to read on a mobile device, or missing beat sheet.
