# Gate 3: Art Director Quality Gate

Sign-off criteria for Phase 3 (Art Bible and Visual Taste).

## Mandatory Sign-Off Criteria

1. **Motion Bible Compliance**:
   - `motion-bible.md` exists and defines color tokens, typography scales, and easing curves.
   - All text and background combinations satisfy WCAG AA contrast (minimum 4.5:1 ratio).
2. **Anti-Slop Visual Standards**:
   - Zero generic AI glows, zero cheap oversaturated gradients.
   - All physical props exhibit bevelled edges, texture noise, and growing contact shadows as they approach surfaces.
   - 3D elements exhibit key, fill, and rim light separation.
3. **Typography Discipline**:
   - Maximum 2 font families per production.
   - Tracking and line heights set explicitly.
   - Zero clipped ascenders or descenders on mobile aspect ratios.

## Verdict Contract

- **PASS**: Motion Bible active, contrast verified, zero visual slop.
- **BLOCK**: Ungrounded floating objects, illegible low-contrast text, or template aesthetics.
