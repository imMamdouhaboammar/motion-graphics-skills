# Beat map

Master clock: `vo.wav`, 54.361 s, 48 kHz mono PCM. Never stretched or edited.

## How the times were measured

1. `ffprobe` for duration.
2. `silencedetect=noise=-38dB:d=0.18` for pauses. Every pause in this read is short (0.18 to 0.26 s), so pauses alone cannot mark beats.
3. `faster-whisper` (small, Arabic, word timestamps) for the start of every word. The transcript's spelling is imperfect; only its timing is used. On-screen text comes from the approved script.

Pauses found (s): 3.47, 5.28, 6.09, 6.90, 9.42, 16.02, 18.69, 21.56, 24.57, 29.81, 31.26, 38.45, 39.90, 42.34, 44.60, 45.97, 48.45, 50.12, 53.29.
