# Studio Specialist Agents (Tier 3)

Roster of specialized production agents operating under studio leadership.

## 1. `kinetic-type-specialist`
- **Domain**: Bold kinetic typography, fast letter slams, rhythm-locked word cuts.
- **Skills**: Archivo Black, Bricolage Grotesque, power4.out snappy easings, beat-synchronized cuts.

## 2. `liquid-glass-specialist`
- **Domain**: Refractive clear liquid glass shaders and multi-plane 2.5D depth.
- **Skills**: SVG turbulence displacement filters, backdrop-filter optics, depth separation.

## 3. `editorial-grain-specialist`
- **Domain**: Print-inspired editorial design, paper noise textures, and classical serif animation.
- **Skills**: Instrument Serif, animated SVG noise layers, imperfect humanized stagger timings.

## 4. `blender-3d-specialist`
- **Domain**: Physical 3D modeling, Cycles ray tracing, and real contact shadows.
- **Skills**: Blender MCP bridge, two-stage clay preview workflows, PBR materials, rim lighting.

## 5. `talking-head-specialist`
- **Domain**: 3D UI compositing around live human speakers.
- **Skills**: Alpha matte separation, 3-plane depth hierarchy (behind, beside, foreground lens), face protection.

## 6. `spec-ad-specialist`
- **Domain**: Unbroken continuous single-shot commercial films.
- **Skills**: One-line one-function filaments, continuous Bezier transitions, mascot medium matching.

## 7. `sound-foley-specialist`
- **Domain**: Tactile audio event mapping and loudness mastering.
- **Skills**: Frame-exact SFX cue placement, click-and-pop foley, FFmpeg loudnorm mastering.

## 8. `opencv-renderer-specialist`
- **Domain**: Headless algorithmic rendering using Python, NumPy, and OpenCV.
- **Skills**: 2.5D geometry interpolation, subpixel Pillow typography, direct FFmpeg piping.

## 9. `color-grading-specialist`
- **Domain**: Color integrity, cinematic grading, and contrast compliance.
- **Skills**: 3D LUT application, black-point pinning, saturation management, WCAG contrast verification.
