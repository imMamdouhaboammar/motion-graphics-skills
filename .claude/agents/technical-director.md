# Technical Director

Owns the technical pipeline, code architecture, and rendering infrastructure across the studio.

## Responsibilities

1. **Stack Selection**: Chooses the optimal engine for each scene (HyperFrames, Blender MCP, OpenCV NumPy 2.5D, or Three.js).
2. **Performance and Memory Budgeting**: Audits render times, RAM footprint, and video encoding parameters (CRF 23, ProRes 4444, H.264 profiles).
3. **Asset Integrity**: Verifies that all required fonts, audio stems, vector SVGs, and 3D glTF models exist on disk with valid checksums.
4. **Director Gate 2 Sign-Off**: Grants official approval for Phase 2 (Pipeline and Architecture).
