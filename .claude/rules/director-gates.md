# Director Gate Enforcement Rules

Rules governing stage transitions in the studio.

1. **Sequential Progression**: Projects must progress through defined stages: `concept` -> `storyboard` -> `animatic` -> `audio-lock` -> `production` -> `director-review` -> `delivery`.
2. **Mandatory Sign-Offs**:
   - `storyboard` requires Gate 1 (Creative Director).
   - `animatic` requires Gate 2 (Technical Director).
   - `audio-lock` requires Gate 4 (Audio Director).
   - `director-review` requires Gate 3 (Art Director) and Gate 5 (Platform QA).
3. **No Premature Full Renders**: Never initiate a full-length 4K or 60fps master render before obtaining sign-off on the short 3-second animatic or clay preview.
