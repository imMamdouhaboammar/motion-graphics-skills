# Motion Graphics Studio Agent Roster

Complete hierarchy of leadership, departmental leads, and specialized production agents.

## Tier 1: Studio Leadership
| Agent | Domain | When to Use |
|---|---|---|
| `creative-director` | High-level creative vision | Narrative hooks, emotional pacing, visual metaphors, Gate 1 sign-off |
| `technical-director` | Pipeline and render stack | Stack choices (HyperFrames, Blender, OpenCV), memory/perf, Gate 2 sign-off |
| `executive-producer` | Production timeline | Beat-sheet milestones, studio stage tracking, deliverable contracts |

## Tier 2: Department Leads
| Agent | Domain | When to Use |
|---|---|---|
| `art-director` | Visual taste and design systems | Motion Bible, color palettes, anti-slop visual auditing, Gate 3 sign-off |
| `audio-director` | Audio storytelling and mastering | Voice-first lock, foley cue design, -14 LUFS mastering, Gate 4 sign-off |
| `safe-zone-qa-lead` | Platform QA and safe zones | Vertical 9:16 safe areas, button clearance, overlay proof, Gate 5 sign-off |

## Tier 3: Specialized Craft Agents
| Agent | Domain | When to Use |
|---|---|---|
| `kinetic-type-specialist` | Kinetic typography | Bold headline slams, word-by-word cuts, Archivo/Bricolage type |
| `liquid-glass-specialist` | Refractive glass shaders | Clear liquid glass, SVG displacement filters, 2.5D card layers |
| `editorial-grain-specialist` | Editorial and analog textures | Paper grain, Instrument Serif, animated SVG noise, magazine aesthetic |
| `blender-3d-specialist` | Physical 3D and Blender | Blender MCP bridge, clay previews, Cycles ray tracing, contact shadows |
| `talking-head-specialist` | VFX around human speakers | 3-depth plane UI around speakers, clean matting, face protection |
| `spec-ad-specialist` | Continuous single shots | Unbroken cinematic films, one-line one-function filaments |
| `sound-foley-specialist` | Tactile sound and foley | Subtle clicks, ticks, chimes, drops, silence before hero hits |
| `opencv-renderer-specialist` | Headless Python rendering | NumPy/OpenCV 2.5D procedural animation without browser engines |
| `color-grading-specialist` | Color science and contrast | LUTs, black level pinning, WCAG contrast verification |
