# Plugin execution rules

This package includes media workflow instructions and bundled reference assets. It does not include the HyperFrames runtime or an authenticated media provider.

Read the requested deliverable and check available host tools before setup. Concept, storyboarding, local asset review and local media operations do not automatically require sign-in. Use existing working project dependencies first.

Install or update dependencies only in the user's authorized project environment. Never update the installed plugin directory in place. Verify commands against the installed HyperFrames CLI help rather than guessing version-specific flags.

Use external media services only with user-authorized account access. Do not transmit client assets, clone a voice, incur paid usage or publish media without authorization for that action. Keep credentials out of generated files and logs.

When shell, renderer or provider access is unavailable, state the missing capability and deliver the supported planning or implementation handoff. Never report a generated asset or render without execution evidence.
