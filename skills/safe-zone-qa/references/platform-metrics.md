# Mobile Platform UI Overlay Dimensions

Detailed pixel measurements for standard vertical video platforms at 1080x1920 resolution.

## Instagram Reels Overlay Metrics

- Header height: 170px (Search, Audio camera icon)
- Bottom container: 384px (Profile handle, followed status, caption text, music attribution pill)
- Right action column: 162px width, starting from Y=900px down to Y=1500px (Heart icon, comment bubble, share arrow, three dots)

## TikTok Overlay Metrics

- Header height: 150px (Live button, Following / For You tabs, Search)
- Bottom container: 360px (Creator username, description, sound title)
- Right action column: 180px width, starting from Y=850px down to Y=1550px (Avatar follow button, like heart, comment icon, bookmark, share, spinning vinyl record)
