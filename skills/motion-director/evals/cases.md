# Motion Director eval cases

These cases test routing, taste, runtime reuse, and production judgment.

## Case 1: Saudi event promo

Prompt:
Create a 55-second Arabic event promo from my final WAV, Thmanyah font files, Four Steps logo, and one editorial collage reference video.

Expected:
- treat WAV as master timeline
- analyze reference across the full duration
- create a beat map
- use Arabic motion rules
- propose three opening mechanisms
- avoid SaaS UI language
- use HyperFrames general or broader video workflow if starting fresh
- use motion-director for art direction
- inspect final frames and full playback

Failure:
- glass cards
- generic icons
- subtitle the full VO
- route to a short unnarrated workflow

## Case 2: Eight-second logo sting

Prompt:
Make an eight-second logo reveal from this SVG.

Expected:
- route to specialist logo or short motion workflow
- avoid full long-film process
- search HyperFrames registry before hand-building a known effect
- preserve exact SVG identity

Failure:
- ask for a full script
- build custom renderer

## Case 3: Existing deterministic project

Prompt:
Polish this working HTML video. The renderer already produces the final MP4.

Expected:
- do not migrate the whole project
- review current render
- preserve deterministic renderer
- fix only art direction and motion problems

Failure:
- rewrite in HyperFrames for no measured benefit

## Case 4: Named glitch transition

Prompt:
Add a glitch transition between these two scenes.

Expected:
- search current project and HyperFrames registry first
- reuse a good existing primitive
- hand-author only if no fitting primitive exists

Failure:
- immediately write a custom shader

## Case 5: True 3D object orbit

Prompt:
The camera must move around a real 3D package and reveal its back panel.

Expected:
- use a true 3D runtime
- Three.js is appropriate
- require real geometry or a suitable model

Failure:
- fake the orbit with CSS rotateY on one flat PNG

## Case 6: Simple text fade

Prompt:
Fade one title in over two seconds and hold.

Expected:
- use the simplest current runtime
- no new dependency
- no custom abstraction

Failure:
- install Three.js
- create a motion engine

## Case 7: Arabic kinetic type

Prompt:
Animate this Arabic sentence word by word with a supplied Arabic display font.

Expected:
- preserve shaping
- default to word-level motion
- verify RTL and font loading
- do not use Latin tracking

Failure:
- character-by-character typewriter without shaping check

## Case 8: Reference matching

Prompt:
Make my video in the same style as this campaign film.

Expected:
- extract grammar
- separate reference brand assets
- create an original composition

Failure:
- copy exact layouts and assets

## Case 9: Music under VO

Prompt:
Put this music track under my narration.

Expected:
- use the runtime audio system
- create room for the voice
- if HyperFrames audio is active, use its voiceover relationship workflow

Failure:
- simply set music to an arbitrary low volume without checking the mix

## Case 10: AI-generated collage asset

Prompt:
Generate a paper cutout prop for this editorial film.

Expected:
- use a media source tool if available
- check fake text and logos
- match shadow, contrast, grade, and material
- keep provenance when supported

Failure:
- drop the raw generated asset into the frame

## Case 11: Data story

Prompt:
Animate monthly revenue from the supplied CSV.

Expected:
- preserve values and scale
- choose a visual mechanism that helps comparison
- avoid decorative distortion
- cite or retain the supplied data source in project notes

Failure:
- invent missing months
- animate all bars with unrelated bounce

## Case 12: Creative-director review

Prompt:
Review this 60-second draft and give me notes by the second.

Expected:
- watch or inspect the actual media
- sample frames
- critique concept, art direction, type, color, composition, motion, and ending
- provide timecoded fixes
- preserve strong ideas

Failure:
- comment only on code
- give generic feedback without timestamps
