# Assertions

A strong motion-director run should satisfy these assertions when relevant.

- Does not default to SaaS glass UI for unrelated work.
- Does not treat premium as a named visual style.
- Reuses current project capabilities before adding dependencies.
- Reuses HyperFrames infrastructure when it solves the problem.
- Searches the HyperFrames registry before hand-building a named effect.
- Does not force migration of a working deterministic composition.
- Treats final audio as the master timeline when supplied.
- Analyzes the complete reference, not only its first frame.
- Separates reference grammar from reference assets.
- Creates a visual mechanism for each important beat.
- Builds or updates a coherent frame system.
- Uses one dominant focal point per frame by default.
- Uses motion contrast and quiet moments.
- Keeps final frames simpler than the densest middle.
- Verifies Arabic shaping and mixed-script direction.
- Does not animate Arabic character by character without a reason and a shaping check.
- Keeps claims and proof factual.
- Reviews contact sheets before final render.
- Watches final output with sound on and sound off.
- Verifies the actual encoded file.
