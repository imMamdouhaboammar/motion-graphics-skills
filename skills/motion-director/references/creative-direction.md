# Creative direction

Motion design starts with still-frame design.

A technically valid composition can still look generic, cheap, crowded, or incoherent. Use this reference to establish the frame before adding motion.

## One frame, one hierarchy

A viewer should know what to look at first within half a second.

Default to exactly one primary focal anchor. Add a secondary anchor only when it supports the primary. Three equal anchors is a failed hierarchy.

Use three layers at most:

1. hero
2. support
3. atmosphere or texture

If four elements have equal contrast, size, and motion, there is no hierarchy.

Simplify before adding movement.

At preflight, test the frame as a thumbnail, in grayscale, with a squint or blur, and at the edges. Fix weak value grouping and accidental tangencies before animation.

## Scale contrast

Strong motion frames often use a large ratio between the hero and everything else.

Examples:

- one huge word and one small label
- one close object and two distant objects
- one large logo and one quiet proof line
- one giant number and a small source

Avoid medium-sized everything.

## Negative space

Negative space is active.

Use it to:

- create anticipation
- isolate a proof point
- prepare a transition
- slow the rhythm
- increase the perceived value of typography
- let a logo or CTA register

Do not fill space simply because it exists.

## Color roles

Name roles before choosing effects.

Typical roles:

- ground
- surface
- ink
- muted ink
- signal
- secondary signal
- proof color
- image color

A brand accent should usually act like a signal, not a flood.

One intentional full-frame brand color can be powerful. Repeating it every scene weakens it.

When official partner or event logos enter, create neutral space around them. Do not recolor them to force palette consistency.

## Color proportion

A simple starting point for branded editorial work:

- 65 to 85 percent ground and neutral surfaces
- 10 to 25 percent ink and imagery
- 5 to 15 percent signal color

This is not a rule for every style. It is a useful check when an accent starts taking over the film.

## Typography is architecture

Do not treat type as captions.

Define roles:

- hero display
- main statement
- question or human voice
- support
- label
- micro detail

Use size, family, weight, width, line height, alignment, and crop to separate roles.

Do not make every headline Black or ExtraBold.

One expressive type moment is stronger than six.

For a display family with alternates or swashes, use those features because the composition needs them, not because they are available.

## Text density

The voice can carry a sentence while the frame carries one phrase.

Ask:

What does the viewer hear?
What one thing should the viewer see?

A screen full of transcript usually means the visual idea has not been solved.

## Composition families

Use variety across a film.

Rotate among:

- full-frame typography
- asymmetric editorial composition
- centered hero object
- wide environmental frame
- close detail
- depth composition
- quiet proof frame
- diagrammatic frame
- image-led frame
- negative-space CTA

Do not repeat the same centered card layout.

## Grid

A grid creates tension only when elements deliberately align to or break it.

Use:

- shared baselines
- repeated margins
- strong vertical anchors
- consistent edge logic
- deliberate crop zones

Avoid accidental near-alignment.

## Safe crop versus accidental clipping

Intentional crop:

- removes part of a large form while preserving recognition
- creates scale
- is repeated as a system
- does not damage meaning

Accidental clipping:

- cuts a descender or diacritic
- clips the last word
- loses punctuation
- makes a logo incomplete
- changes from frame to frame without purpose

## Depth

Depth can come from:

- scale
- occlusion
- shadow
- blur
- perspective
- parallax
- lighting
- overlap
- focus

Do not use all of them at once.

Choose a few and keep them consistent.

## Shadow system

Define a small elevation system.

Example:

Low:
- paper card
- short offset
- tight soft shadow

Medium:
- poster
- pass
- cutout prop
- moderate offset

High:
- hero prop
- foreground object
- stronger separation

Do not make every object float.

## Texture

Texture should explain material.

Paper grain belongs to paper.
Film grain belongs to footage.
Halftone belongs to print treatment.
Noise does not automatically make a frame editorial.

Texture should be noticed after the design, not before it.

## Image treatment

When mixing photos, generated assets, vectors, and diagrams, unify them.

Possible unifiers:

- shared color grade
- shared paper edge
- shared cutout logic
- shared shadow direction
- shared contrast
- shared grain
- shared border or matte

Do not alter official marks to force them into the style.

## Generated imagery

AI-generated imagery can be a source asset, not a visual system by itself.

Before using it:

- remove fake text
- remove accidental logos
- check anatomy and object logic
- match perspective to the scene
- match light direction
- match grain and contrast
- crop decisively
- preserve provenance when the production system supports it

If the generated image is only decorative, question whether it needs to exist.

## Style territories

Use these as starting territories, not templates.

### Editorial print

Good for:
- events
- culture
- institutions
- documentaries
- campaigns

Materials:
- paper
- photography
- display type
- cutouts
- marks
- printed diagrams

### Swiss kinetic

Good for:
- corporate clarity
- design-led announcements
- abstract concepts

Materials:
- grid
- type
- blocks
- rules
- disciplined accent color

### Broadcast package

Good for:
- sports
- news
- conferences
- recurring content systems

Materials:
- modular panels
- lower thirds
- data
- transitions
- brand geometry

### Cinematic minimal

Good for:
- luxury
- technology
- architecture
- prestige

Materials:
- darkness
- light
- few objects
- slow camera
- precise type

### Technical schematic

Good for:
- systems
- engineering
- logistics
- process

Materials:
- paths
- diagrams
- nodes
- plans
- labels

### Tactile collage

Good for:
- human stories
- history
- culture
- events

Materials:
- cutouts
- paper
- tape
- torn edges
- texture
- handwritten marks

### Geometric brand world

Good for:
- identity films
- logo systems
- campaigns

Materials:
- one or two brand primitives
- repetition
- transformation
- modular geometry

## The premium test

Premium is not a style.

A frame feels considered when:

- the hierarchy is obvious
- every element earns its place
- materials agree
- spacing is deliberate
- the accent color is controlled
- typography has contrast
- the composition survives as a still
- nothing looks like a default component
