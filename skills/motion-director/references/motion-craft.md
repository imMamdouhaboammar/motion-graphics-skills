# Motion craft

Use this reference after the frame system is clear.

Motion should explain relationships, not decorate finished layouts.

## The motion question

For every move, ask what changes:

- attention
- identity
- location
- scale
- state
- time
- depth
- ownership
- cause and effect

If nothing meaningful changes, the motion is probably decorative.

## Timing

Timing communicates weight and intent.

Fast:
- response
- snap
- interruption
- urgency
- small distance

Slow:
- importance
- scale
- reveal
- ceremony
- depth
- large distance

Larger travel usually needs more time than smaller travel.

Use duration contrast. Do not give every move the same 400 ms timing.

## Spacing

Spacing is how speed changes over time.

Good spacing makes motion feel physical even when the object is abstract.

Use:

- fast departure, smooth arrival for focus changes
- restrained overshoot for elastic material
- constant speed only when mechanical or informational meaning requires it
- stepped timing for handmade or stop-motion texture

Do not use bounce as a universal finishing move.

## Anticipation

Anticipation prepares the eye.

Examples:

- a card compresses before expanding into a screen
- a spotlight tilts before sweeping
- a word shifts before the whole line exits
- a camera settles before a title lands

Keep anticipation short. The viewer should feel it before consciously reading it.

## Follow-through

Parts of a system do not always stop at the same instant.

Use follow-through for:

- paper
- cables
- hanging passes
- stacked cards
- loose type fragments
- particles

Do not apply it to rigid UI or mechanical diagrams unless the style supports it.

## Stagger

A small stagger can turn a slide into choreography.

Stagger by:

- spatial order
- reading order
- hierarchy
- depth
- causality

Do not stagger every list simply because it has multiple items.

## Holds

A hold is where understanding happens.

A good beat often follows:

- prepare
- move
- settle
- hold
- hand off

The hold can contain subtle secondary motion, but the primary idea must be readable.

## Motion contrast

Use contrast between scenes.

Examples:

- frantic backstage planning to one quiet brand frame
- dense card corridor to one isolated proof mark
- full camera move to a locked type frame
- smooth 30 fps camera with 15 fps handmade marks

Contrast creates rhythm.

## Motion on twos

Use stepped motion selectively when the material should feel hand-made, printed, cut, or stop-motion.

Good candidates:

- doodles
- paper snaps
- marker lines
- grain changes
- collage jitter
- small decorative pieces

Keep camera motion and important spatial movement smooth unless the entire style is intentionally stepped.

## Transformation

Transformation is one of the strongest motion mechanisms.

Strong:
- button becomes player
- plan becomes stage
- ring becomes clock
- word becomes grid
- card becomes workspace
- path becomes chart
- logo primitive becomes scene geometry

Weak:
- object fades out
- unrelated object fades in

Use dissolve only when continuity is not important.

## Shared-object transition

Carry one element across the cut.

It can preserve:

- position
- color
- shape
- movement
- direction
- edge
- line
- texture

This is how scenes feel connected.

## Occlusion transition

Let a foreground object pass in front of the frame and reveal the next scene.

Works well with:

- paper
- signage
- people when footage exists
- cards
- stage structures
- type
- doors

Use it to hide a state change, not as a random wipe.

## Match cut

Match shape, scale, direction, or composition between two different objects.

Examples:

- spotlight circle to stopwatch
- stage screen to social post
- badge rectangle to run-of-show sheet
- camera viewfinder to media frame

## Camera

The camera should move because the story changes depth, scale, or location.

Use:

- push in for detail
- pull out for context
- pan for discovery
- orbit for form
- rack focus for hierarchy
- crane-like movement for scale

Do not add a camera drift to every still composition.

## 2.5D

2.5D is enough when the illusion comes from planar layers.

Use:

- foreground
- subject plane
- background
- parallax
- shadow
- perspective
- occlusion

It is often cheaper and clearer than true 3D.

## True 3D

Use true 3D when the shot depends on:

- geometry
- real camera parallax
- changing occlusion
- materials
- lighting
- 3D path
- object rotation that reveals hidden surfaces

When HyperFrames is active, prefer its supported Three.js adapter rather than inventing a capture path.

## Masks

Masks are useful for:

- type reveals
- image reveals
- object handoffs
- wipes that belong to an object
- spatial transitions

A mask should usually have a visual reason.

## Paths

A path can become a story spine.

Good path roles:

- route
- timeline
- wire
- guest journey
- camera cable
- map
- workflow
- growth
- connection

If a line appears only to fill empty space, remove it.

## Morphing

Morph when the visual relationship is understandable.

The viewer should be able to answer why A becomes B.

If the shapes have no conceptual connection, a morph becomes a trick.

## Kinetic type

Think in units:

- phrase
- line
- word
- glyph
- outline

Choose the smallest unit that helps meaning.

Per-character animation is not automatically more advanced.

For Arabic, word and line animation are safer defaults because glyphs join.

Read arabic-motion.md.

## Text motion mechanisms

Useful patterns:

- masked rise
- baseline travel
- scale compression
- word handoff
- crop reveal
- tracking change for Latin only when appropriate
- width change on a variable font
- shape-to-type
- type-to-layout
- foreground type occlusion
- type on a path

## Data motion

Preserve data meaning.

Use motion to show:

- change
- ranking
- comparison
- accumulation
- flow
- causality

Avoid:
- decorative bouncing bars
- axes changing silently
- pie slices that distort data
- arbitrary easing that makes one value look more important

## Scene rhythm

A useful rhythm model:

1. hook
2. establish
3. accelerate
4. proof
5. quiet reset
6. build
7. payoff
8. CTA
9. clean resolve

Do not copy this mechanically. Use it to detect a film that has no reset or no payoff.

## Endings

A common failure is adding more ideas in the last three seconds.

Do the opposite.

Resolve.

Clear secondary elements.
Let the final claim land.
Then hold the brand or CTA long enough to register.

The final frame should be simpler than the densest middle frame.
