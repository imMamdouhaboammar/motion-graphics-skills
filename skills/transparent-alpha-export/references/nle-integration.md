# Non-Linear Editor Integration Guide

Instructions for importing alpha transparent motion graphics into professional editing suites.

## DaVinci Resolve Setup

1. Import the ProRes 4444 MOV file into the Media Pool.
2. Verify Clip Attributes: ensure Alpha Mode is set to Premultiplied or Straight according to the render profile.
3. Drop the clip on Video Track 2 above your live action footage on Video Track 1.

## Adobe Premiere Pro Setup

1. Import the ProRes 4444 MOV or PNG image sequence.
2. If importing PNG sequence: select the first image and check the Image Sequence checkbox in the import dialog.
3. Interpret Footage: ensure Alpha Channel is set to Premultiplied Alpha.
