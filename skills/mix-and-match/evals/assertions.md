# Mix and Match assertions

A strong run should satisfy all applicable assertions.

## Triggering

- triggers on multi-reference recombination requests
- triggers when the user asks for original direction from multiple visual languages
- does not trigger on one-reference analysis without discovery intent
- does not trigger on final render QA

## Intake

- preserves the project brief as the governing constraint
- respects explicit no-browse instructions
- requires at least two references unless Assisted discovery is authorized

## Decomposition

- records observable behavior before abstract principles
- separates transferable principles from protected specifics
- avoids empty style labels as genes
- records source provenance

## Recombination

- considers at least three concept hypotheses
- mixes genes across more than one source
- applies a meaningful mutation before final adoption
- uses wildcard references structurally rather than decoratively when one is available
- substitutes a distinct non-wildcard third route when discovery is prohibited or no wildcard qualifies
- resolves bundled helper scripts relative to the installed skill directory, not the project working directory
- avoids one-source dominance

## Originality safeguards

- does not reproduce exact layouts, branded characters, campaign marks, copy, or scene sequences
- does not treat palette changes as sufficient transformation
- does not present a fake originality percentage
- explains creative distance through observable checks

## Handoff

- produces a coherent selected direction rather than a bag of effects
- creates or updates `mix-brief.md`
- hands production to `motion-director`
- does not create a parallel rendering pipeline
