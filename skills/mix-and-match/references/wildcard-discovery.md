# Wildcard discovery

Wildcard references exist to widen the search space, not to add more mood board images.

## When to search

Search only when one of these is true:

- primary references are visually too similar
- every obvious concept looks derivative
- one creative dimension is missing, such as material, spatial logic, transition logic, or rhythm
- the user explicitly asks for outside inspiration

Do not search after the concept already has a coherent system and passes the creative distance audit.

## Pick a missing dimension first

Before searching, name the gap.

Examples:

- `We have rhythm and typography, but no spatial idea.`
- `All references use screen-native surfaces. We need a physical material rule.`
- `The cuts are strong, but there is no recurring handoff mechanism.`

Then search a distant discipline that can answer that gap.

## Domain map

| Missing dimension | Useful wildcard domains |
|---|---|
| spatial logic | architecture, exhibition design, stage design, wayfinding |
| material | packaging, printmaking, industrial design, textiles |
| movement | choreography, kinetic sculpture, mechanical systems |
| hierarchy | editorial design, signage, maps, information design |
| transition | title design, theatre scene changes, mechanical interfaces |
| light | photography, stage lighting, architecture |
| sequence | comics, storyboards, museum journeys, rituals |
| constraint | Swiss print, signage systems, industrial manuals, scientific diagrams |

## Search behavior

When web or image search is available:

1. search the selected domain plus the missing mechanism
2. inspect actual images or footage, not only text descriptions
3. prefer one strong reference over ten weak ones
4. capture provenance
5. stop after 1 to 3 useful wildcards

Avoid searching only for `best motion design`, `cool animation`, or the same named studio repeatedly.

## Wildcard acceptance

A wildcard must answer at least one question:

- What new mechanism does this source introduce?
- What constraint does it teach?
- What spatial or material behavior can be translated into motion?
- What does it make possible that the primary references did not?

If it cannot answer one, drop it.

## Distance without chaos

The wildcard should be distant from the references but relevant to the brief.

Bad distance is arbitrary.

Good distance creates a bridge that can be explained.

Example:

`The motion references all use hard cuts. A wayfinding map adds a continuous route rule, which solves continuity without copying another motion reel.`
