# Creative recombination

Use this when the first mix still feels like a reference collage.

## The problem with averaging

Averaging usually preserves the most obvious surface traits from each source. The result may contain more influences but still feel less original.

Do not ask what 50 percent of one reference and 50 percent of another looks like.

Ask what rule from one source can change the function of a rule from another source.

## Productive relationships

### Mechanism plus material

Take a motion mechanic from one source and express it through the physical world of another.

Example:

- source A: a mask reveals content by expanding
- source B: folded paper changes surface orientation
- recombination: a paper fold becomes the reveal mask and also changes the scene plane

### Rhythm plus hierarchy

Take timing from one source and focal logic from another.

Example:

- source A: fast fast fast quiet
- source B: one giant word with tiny peripheral proof
- recombination: three rapid object transformations resolve into one oversized word and a long still hold

### Constraint plus metaphor

Take a formal restriction from one source and use it to sharpen the project idea.

Example:

- source A: only one moving object per frame
- source B: route maps organize information through one continuous line
- recombination: one moving line becomes the only animated object and changes role across every scene

### Spatial rule plus typography

Let a spatial system determine type behavior.

Example:

- source A: architecture reveals rooms through thresholds
- source B: type is cropped at frame edges
- recombination: Arabic phrases behave like rooms revealed through moving typographic thresholds

## Mutation verbs

When a borrowed principle feels too recognizable, apply one mutation deliberately.

- invert
- compress
- expand
- spatialize
- flatten
- reverse
- interrupt
- repeat
- subtract
- materialize
- dematerialize
- translate between media
- change actor
- change scale
- change time
- change consequence

Do not stack mutations merely to look novel. One meaningful transformation is better than five decorative distortions.

## Build concept sentences

A concept sentence should describe a system, not a mood board.

Weak:

`Editorial collage with Apple pacing and cool typography.`

Stronger:

`One route line behaves like an edit decision, cutting through tactile Arabic layouts and turning each cut into the material of the next scene.`

The stronger version can generate scenes without naming a reference.

## Kill tests

Reject a concept when any answer is yes:

- Can a reviewer identify one reference from the first frame alone because the layout is nearly unchanged?
- Does the concept require exact source assets to work?
- Is the source relationship still visible as separate chunks rather than one visual system?
- Is the wildcard only a texture or decoration?
- Would the same concept work unchanged for an unrelated brief?
- Is novelty coming from randomness instead of a meaningful connection?

## The useful surprise rule

A surprising connection is useful only when it improves one of these:

- meaning
- hierarchy
- continuity
- emotion
- memorability
- production clarity

If the surprise improves none of them, remove it.
