# 日式動畫賽璐璐風（動漫感角色與演出）

## 辨識特徵
- 畫面：乾淨有粗細變化的線稿、平塗上色＋一階硬陰影＋高光、大眼睛、頭髮成束、漂亮的漸層天空與雲
- 演出：速度線、集中線、衝擊畫面、閃光、誇張表情（汗滴、青筋、星星眼、豆豆眼）、一拍二／一拍三的動作
- 剪接：日劇動畫式的鏡頭語言（特寫表情、反應鏡頭、定格＋鏡頭搖）
- 常見題材：校園、日常搞笑、青春、MV

## 製作預設
- 1920×1080、24 fps；角色動作 onTwos，鏡頭平移可平滑
- 角色一律原創（不可模仿既有動漫角色），用引擎的 cast.js 起手改造型
- 字幕用動畫字幕樣式（白字深色描邊），確保手機看得清楚
- 所有 API 與畫法規則以 `.claude/skills/anime-cel/SKILL.md` 和 `GUIDE.md` 為準

## 已知的坑
- 側面角度最弱（後腦頭髮像平台），重要演技用正面或 3/4 側
- 沒有背面、低頭／抬頭、坐姿的現成姿勢；需要時用鏡頭與構圖避開
- 手是簡化版，特寫手部的鏡頭要少
- 動作用 onTwos；表情變化用 `faceAt()`（眨眼＋小彈跳），不要瞬間切換
- （之後每次製作學到的新坑補在這裡）
