# 蠟筆／色鉛筆繪本風（溫暖童書感）

## 辨識特徵
- 畫面：蠟筆或色鉛筆筆觸、看得到紙張紋理（蠟筆在紙紋上斷斷續續）、柔和粉彩色、線條略帶童趣
- 構圖：像繪本內頁，留白多、常有頁面邊框或暈邊
- 轉場：翻頁、淡入淡出
- 常見題材：童話、親子、溫馨故事、睡前故事；常配旁白

## 製作預設
- 1920×1080、24 fps；線稿慢慢地 boil（像重畫的手繪動畫）
- 角色一律原創，用引擎的 cast.js 起手改造型
- 字幕用繪本字體，確保手機看得清楚
- 所有 API 與畫法規則以 `.claude/skills/crayon-storybook/SKILL.md` 和 `GUIDE.md` 為準

## 已知的坑
- 遠景角色太小會看不清表情 → 情緒重點用中景以上，u 至少 30
- 渲染較慢（約 150–400 ms/格，翻頁那幾格更久），30 秒片光整片渲染就要 15–30 分鐘；長渲染照規則分段前景跑
- Lulu 手臂短，舉手只到耳朵高度 → 拿高處的東西先量手的位置再擺道具
- 刺蝟 Kuri 的 3/4 和側面比正面僵，演技鏡頭優先用正面
- 用的是修補過的 p5.brush（避免疊色變髒）；npm install 時自動產生，若出現警告代表 p5.brush 版本改了
- （之後每次製作學到的新坑補在這裡）
