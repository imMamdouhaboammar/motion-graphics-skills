# 白板手繪解說（邊畫邊講）

## 辨識特徵
- 畫面：白板或白紙底、麥克筆線條一筆一筆畫出來、常有一隻手拿筆跟著畫
- 內容：解說、教學、觀念說明；大量箭頭、圈選、圖示、手寫字
- 鏡頭：在一大片白板上平移／縮放到下一段內容，或用板擦擦掉換頁
- 聲音：通常有旁白，配輕快背景音樂

## 製作預設
- 1920×1080、24 fps；旁白節奏決定每段畫多快（一句旁白畫完一個重點）
- 手寫字與重點詞要大、要在手機上看得清楚；每個畫面只講一件事
- 角色（若有）一律原創，用引擎的 cast.js 起手
- 所有 API 與畫法規則以 `.claude/skills/whiteboard/SKILL.md` 和 `GUIDE.md` 為準

## 已知的坑
- 手固定從右下角進出，排版時把重點放在左上到中間，避免被手擋住
- 手寫字是斜向揭露，不是真正的筆順；中文字幕一行不要太長
- 角色是簡單塗鴉，只有 3 個視角；動作以「畫出來＋簡單姿勢」為主，不要排複雜走位
- 場景裡沒出現、但字幕會用到的文字，要加進 `window.WB_TEXT` 讓字型預先載入
- （之後每次製作學到的新坑補在這裡）
