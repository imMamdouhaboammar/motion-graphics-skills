# 旁白漫畫 vlog（第一人稱旁白＋一句一圖的 Q 版漫畫，說自己的故事、以好笑的方式畫出來）

## 辨識特徵
- 畫面：扁平向量漫畫，粗描線、純色平塗、大頭小身的 Q 版角色；情緒爆點切換成誇張醜化的大特寫
- 剪接：一句旁白 ≈ 一張圖 ≈ 一鏡，平均 2–3 秒，切點跟著旁白走、不跟音樂拍
- 聲音：第一人稱旁白為主，背景音樂＋卡通音效
- 文字：全程硬字幕（旁白逐句），章節字卡、大字數字（金額、次數）
- 結構：開場快切預告 → 章節字卡 → 「入坑 → 爽 → 被坑 → 自嘲」的小循環 → 回扣開場、問觀眾

## 製作預設
- engine：hyperframes；**角色一律用 `../assets/vector_rig/`（骨架＋一體輪廓）**，每個角色一份定義放共用檔，鏡頭只給姿勢參數。
  禁止在鏡頭裡用圓形、長方形另外拼頭、身體、手臂、手。
- 角色設定圖（正面、表情 8+、本片用到的姿勢 6+）先過角色關再做鏡頭。
- 特寫鏡頭用 `scale` 放大同一個角色（線寬會跟著變粗），不要另外畫一個「特寫版」頭。
- 醜化大特寫：用誇張表情（scream / cry / evil…）＋放大＋速度線背景，仍是同一個角色。
- 旁白：使用者提供錄音最好；沒有就用 TTS（media-use），字幕跟旁白逐句對齊。
- 1920×1080、30 fps，片長依需求（預設 60 秒）。

## 已知的坑
- 角色拼接感（手浮空、沒脖子、關節兩層描邊）→ 就是沒用 vector_rig 造成的。
- HTML 裡 `<svg>` 預設 overflow:hidden：鏡頭拉遠或平移時邊緣被切 → 角色所在的 svg 設 overflow:visible。
- vector_rig 的 3/4 側身（turn > 0.5）目前較弱，主要用正面與小角度側身。
