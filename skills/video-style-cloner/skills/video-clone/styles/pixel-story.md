# 像素風故事短片（復古遊戲感）

## 辨識特徵
- 畫面：看得到方塊像素、有限色盤、抖色（dither）漸層、1 像素描邊；角色像遊戲精靈圖
- 動作：角色動作是一格一格的（8–12 fps），鏡頭平移很順；常有遊戲 UI 元素（對話框、血條、!）
- 剪接：節奏偏快，常用像素溶解、菱形／方塊轉場
- 聲音：8-bit／chiptune 或 lo-fi 配樂常見

## 製作預設
- 1920×1080、24 fps；引擎內部低解析度畫、最近鄰放大，鏡頭與位置都對齊像素
- 角色一律原創，用引擎的 cast.js 起手改造型
- 字幕用引擎的像素風字幕（全解析度繪製，確保手機看得清楚）
- 所有 API 與畫法規則以 `.claude/skills/pixel-art/SKILL.md` 和 `GUIDE.md` 為準

## 已知的坑
- 角色在 1× 很小（40–65 像素高），演表情的鏡頭用 `punch(2)` 放大；同一段內盡量不要混用不同像素大小
- 手臂最高只到頭部高度；側面舉手會擋到臉 → 伸手拿高處的東西用正面
- 轉身是直接換視角（沒有中間格），用快速動作或鏡頭切換遮掩
- 字幕用 `say()`（預設 3 倍大，手機看得清楚），一行最多約 20 個中文字；太長就拆成兩句
- DotGothic16 缺少部分繁體字（例：你），會自動改用 Noto Sans TC 顯示，字形略有不同
- 方塊（blocks）／抖色轉場：前一鏡蓋滿後，下一鏡要立刻開始揭開，中間不可以有 ≥ 3 格幾乎全黑的畫面（實測出現過 4 格黑場，看起來像眨眼）
- 抖色溶解不要整個畫面同時鋪均勻的 1 像素點陣（像蓋一層紗窗）→ 用從中心往外擴散的窄環抖色，同一支片的溶解手法要一致
- 對白：打字打完後至少停 1.2 秒再關框（最後評審第一輪唯一的必修就是這個）
- 12 fps 下大姿勢變化（坐下、蜷起來、轉身）要加一格中間姿勢；尾巴、耳朵不能一格就瞬移到另一邊
- 遠景雪原／草原裡角色只有十幾像素，情緒只能靠動作和 emote（! ?）傳達；要看表情的段落切中景或 `punch(2)`
- 煙、霧、火花這類效果不要用規則的格子圖樣，放大看會像符號（#）；用不規則的抖色團塊
