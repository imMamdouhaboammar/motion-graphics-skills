# 剪紙／定格動畫（紙材、手作感）

## 辨識特徵
- 畫面：看得出紙張纖維、剪裁邊緣不規則、每一層有投影、角色是關節紙偶（看得到釘扣）
- 動作：有定格動畫的頓挫感（每秒 8–12 張）、位置每格微微抖動
- 轉場：紙張滑入、翻卡、撕紙、立體書展開
- 常見題材：童趣故事、手作風廣告、溫馨短片

## 製作預設
- 1920×1080、24 fps；角色動作用 onStep 保持定格頓挫，鏡頭可平滑
- 角色一律原創，用引擎的 cast.js（紙偶關節）起手改造型
- 字幕做成剪紙字或紙標籤，確保手機看得清楚
- 所有 API 與畫法規則以 `.claude/skills/paper-cutout/SKILL.md` 和 `GUIDE.md` 為準

## 已知的坑
- 女孩角色 lulu 臉比較小，情緒重點用中景以上或特寫，遠景只做動作
- pom 手臂短，舉手只到頭旁邊 → 拿高處的東西改成從側面或跳起來
- 沒有側面／背面，轉身是換圖；表情是瞬間切換（用眨眼遮住），沒有嘴型對嘴
- 淺色薄紙疊在深色上會變髒，重要的色塊不要用 tissue 蓋
- 形狀大小做動畫會讓剪裁邊閃爍 → 改用 sx/sy、popUp 或鏡頭縮放
- 後面接快照式轉場（trBook/trTear/trFlip）的鏡頭，自己不要畫出場轉場，而且要能畫到結束時間之後
