# Local SFX assets

This package ships no sound files. `manifest.json` is empty; it does not advertise unavailable assets or licenses.

To use offline SFX, add audio files that you have permission to use to this directory and add entries to `manifest.json` with `file`, `duration` (seconds), and optional `description`. Record each asset's source and license here. No source or license is implied for user-supplied files.
